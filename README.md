# Painel PMI — S&P Global

Dashboard de acompanhamento dos PMIs (S&P Global): zona do euro desde 2007, Europa por país e painel global.

- **Página:** https://anapdav.github.io/painel-pmi/
- Headline numbers compilados dos press releases públicos da S&P Global (pmi.spglobal.com) e de histórico próprio.
- Atualização: flash (~dia 23-24) e fechamentos mensais.

*Uso pessoal/educacional. PMI™ é marca da S&P Global; os números aqui são os divulgados publicamente nos press releases.*
